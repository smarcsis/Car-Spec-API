# Car Spec Search
Car spec search tool
A browser-based car specification search tool built with **HTML, CSS, JavaScript, and JSON**.

This project allows users to search through vehicle data and quickly find matching cars and specifications. I built it as one of my first larger independent projects outside of school to strengthen my JavaScript skills and better understand how multiple files work together in a complete application.

---

## Features
- Search for vehicles by name
- Supports partial search terms
- Displays matching vehicle information and specifications
- Handles searches with no matching results
- Uses JSON data to store and retrieve vehicle information
- Interactive functionality built with JavaScript
- Responsive layout for different screen sizes

## Running the Project

1. Clone or download this repo
2. Open the project folder in **VS Code**
3. Open `index.html` in your browser

For the best experience, the project can also be opened using a local development server such as the **Live Server** extension for VS Code.
